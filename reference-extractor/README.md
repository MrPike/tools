# Reference Extractor

Extract the reference list from any academic PDF into structured
[CSL-JSON](https://citeproc-js.readthedocs.io/en/latest/csl-json/markup.html),
and preview it re-rendered in popular citation styles — entirely in the browser.

**Live:** <https://tools.pike.im/reference-extractor/>

## What it does

Drop a PDF onto the left pane (or click to browse) and it:

- Finds the References / Bibliography / Works Cited section automatically.
- Splits it into individual entries, whatever the citation style — numbered
  (`[1]`, `1.`, `1)`), superscript-numbered, or author–year with hanging
  indents — using text geometry (column ordering, indent offsets, superscript
  detection) as well as text patterns.
- Cleans up real-world PDF artifacts: wrapped and hyphenated lines, ligature
  code points, running headers/footers, page numbers, DOIs split across lines,
  two-column interleaving.
- Parses each entry into CSL-JSON: authors (family/given, incl. `et al.` and
  organisational authors), year, title, container-title, volume/issue/pages,
  DOI, URL, and item type (journal article, book, chapter, conference paper,
  thesis, web page, …).
- Shows the result in the right pane as either pretty-printed JSON or a
  formatted reference list re-rendered by
  [citeproc-js](https://citeproc-js.readthedocs.io/) in a choice of preset
  styles (APA 7, MLA 9, Chicago author–date, Harvard, Vancouver, IEEE).
- Exports the whole bibliography as a `.csl.json` download or clipboard copy.

No references section detected, or a scanned PDF? Paste the bibliography into
the box on the left and parse that instead.

## Privacy / how it works

Everything runs locally in your browser — nothing is uploaded, no network
calls are made, and the page works offline. pdf.js (Mozilla, Apache-2.0) is
bundled inline in `index.html`; the parser (`parser.js`), citeproc-js
(`citeproc.js`) and the preset CSL styles (`styles.js`) are plain local
scripts, so the tool also works from `file://`.

## Development

- `index.html` — the tool (UI + inline pdf.js, no build step; edit directly).
- `parser.js` — the bibliography parser (also used by the tests below).
- `citeproc.js` — vendored citeproc-js v2.4.63 (one-line patch: the trailing
  `module.exports` is guarded with `typeof module` so it also loads in browsers).
- `styles.js` — preset CSL styles + locale, generated by `dataset/generate.mjs`.
- `dataset/` — synthetic test corpus: 24 ground-truth CSL-JSON references rendered
  by citeproc into 10 citation styles × clean/messy PDFs. See `dataset/README.md`.
- `tests/` — `run.mjs` (node unit tests), `e2e.mjs` (node end-to-end over the
  dataset PDFs via pdfjs-dist), `harness.html` (same, in a real browser).

Run the tests from this directory:

```
node tests/run.mjs   # parser unit tests (no pdf.js)
node tests/e2e.mjs   # full pipeline over the 20 dataset PDFs
```

Current e2e accuracy (clean PDFs): 10/10 styles pass — 24/24 entries segmented,
98% author, 99% year accuracy. Messy variants (hyphenation, page breaks,
headers/footers, ligatures, two-column) reach 92–100% author+year on 9 styles.
